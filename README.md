# KOFit

KOFit es una landing page enfocada en la venta de equipamiento y accesorios para personas que practican boxeo.

El proyecto fue desarrollado durante un hackathon con el objetivo de crear una página moderna, atractiva, funcional y adaptable a diferentes dispositivos.

## Descripción

La landing page presenta información sobre KOFit, sus productos, beneficios, testimonios, planes y medios de contacto.

La identidad visual utiliza colores oscuros, blanco y rojo para transmitir fuerza, disciplina, energía y rendimiento.

## Secciones de la página

- Inicio o Hero
- Acerca de KOFit
- Servicios y productos
- Testimonios
- Planes o precios
- Contacto
- Footer

## Características

- Diseño responsive para computadora, tableta y celular.
- Navegación interna entre secciones.
- Uso de componentes y clases de Bootstrap.
- Botones de llamada a la acción.
- Íconos de Bootstrap Icons.
- Identidad visual coherente con la temática de boxeo.
- Código HTML semántico y organizado.
- Estilos CSS reutilizables.
- Interacciones desarrolladas con JavaScript.

## Objetivo del proyecto

El objetivo de KOFit es ofrecer una experiencia visual clara y atractiva para personas interesadas en el boxeo, facilitando el acceso a productos, beneficios e información relevante para su entrenamiento.

## Propuesta de valor

KOFit busca acompañar a cada atleta dentro y fuera del ring mediante equipamiento confiable, atención personalizada y una experiencia de navegación sencilla.

## Trabajo colaborativo

El proyecto fue desarrollado por un equipo de seis integrantes. Cada persona trabajó en una sección distinta mediante ramas de Git, lo que permitió organizar el desarrollo y unir posteriormente todos los cambios en la rama principal.
